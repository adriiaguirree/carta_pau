# Carta digital para Paulina

Regalo interactivo de cumpleaños con un corazón animado y una carta que aparece con efecto de máquina de escribir.

## Abrir el regalo

No necesitas instalar nada. Abre `index.html` directamente en tu navegador.

Desde VS Code:

1. Abre esta carpeta del proyecto.
2. Abre el archivo `index.html`.
3. Haz clic derecho dentro del archivo y elige `Open with Live Server` si tienes esa extensión.
4. Si no tienes Live Server, busca `index.html` en el explorador de archivos de tu computadora y dale doble clic.

## Uso

- Clic en `Abrir carta` o presiona `Enter` para pasar del corazón a la carta.
- Clic en `Ver completa` para mostrar toda la carta.
- Clic en `Volver al corazón` o presiona `Escape` para reiniciar.
